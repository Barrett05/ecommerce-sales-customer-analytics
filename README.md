# E-Commerce Sales & Customer Analytics

## Project Overview

This project analyses a simulated e-commerce dataset using Google BigQuery (SQL) and Looker Studio to identify sales trends, product profitability, and customer purchasing behaviour.

## Tools Used

- **SQL (Google BigQuery):** Data extraction, joins, aggregations, and business metrics
- **Looker Studio:** Interactive dashboard and KPI visualisation
- **GitHub:** Project documentation and portfolio presentation

## Business Questions

1. How has revenue changed over time?
2. Which product categories generate the most revenue and gross profit?
3. Which categories have the highest gross profit margins?
4. How do repeat customers compare with one-time customers?

## Key Findings

- Completed orders generated approximately **$2.74 million** in revenue.
- There were **31,857 completed orders**, with an average order value of approximately **$86**.
- **Outerwear & Coats** generated the highest revenue and gross profit.
- **Blazers & Jackets** achieved the highest gross profit margin.
- Repeat customers spent more per customer on average than one-time customers.

## Business Recommendations

- Improve customer retention through loyalty programmes and targeted marketing.
- Prioritise profitable product categories while monitoring their margins.
- Track monthly revenue, order volume, and average order value to identify performance changes.
